# Medical College Attendance System

An AI-powered medical college website to manage student attendance, timetable publishing, and automatic percentage tracking.

## Features
- AI-assisted timetable upload and auto-sync
- Department attendance updates
- Student attendance dashboard with automated percentage
- Alert insights for low attendance
- Premium, modern UI

## Run locally

### 1) Install project dependencies
```bash
npm install --prefix backend
npm install --prefix frontend
```

### 2) Start the app
```bash
npm run dev
```

This runs:
- Frontend: http://localhost:3000
- Backend: http://localhost:3001

## Stack
- Frontend: React + Vite + CSS
- Backend: Node.js + Express
- AI flow: simulated AI processing for timetable interpretation and attendance analysis

## Notes
This project is structured as a polished demo-ready prototype for a medical college attendance system with automation-first workflows.
